# Project Overview

## Mission
Manarat Al-Tareeq aims to become one of the largest Arabic scientific communities by integrating education, research, AI, collaboration, mentoring, and innovation into a single platform.

## Target users
Undergraduate students, medical students, researchers, professors, supervisors, universities, research centers, healthcare professionals, scientific organizations.

## Main sections (20)
1. Home
2. Dashboard (role-personalized)
3. AI Research Assistant (RAG-based)
4. Research Roadmaps

Each section is specified individually in `06-features-catalog.md` — with its tables, status, and rules — before any of it is built.

## Roles
`student`, `research_member`, `research_leader`, `supervisor`, `admin`, `founder`. A user may hold more than one role simultaneously. See `01-constitution.md` §3 for how roles are enforced, and `06-features-catalog.md` → Dashboard for what each role sees.

## What this product is explicitly NOT
- Not a generic Udemy/Coursera clone — courses are one of many resource types feeding into research and mentoring, not the center of the product.
- Not a place where AI invents scientific claims — see the RAG constraint in `01-constitution.md` §3.
- Not a single-language product with Arabic as an afterthought — Arabic/RTL is primary.
